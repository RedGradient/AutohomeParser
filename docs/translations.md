# Переводы и нормализация

Pipeline переводит только нормализованные поля. `raw_json` сохраняется в том
виде, в котором пришёл из Autohome, и используется для аудита и повторной
обработки.

## Словари

Основной файл `autohome/data/translations_ru.json` содержит названия
характеристик и повторяющиеся значения. Контекстные словари разделены по
назначению:

- `brand_names.json` — официальные международные названия брендов;
- `series_names.json` — международные или общепринятые названия серий;
- `vehicle_name_suffixes.json` — устойчивые обозначения версий;
- `spec_name_fragments.json` — фрагменты названий комплектаций;
- словари батарей, силовых установок и нормализованных технических кодов.

Полное совпадение автомобильного имени имеет приоритет перед заменой отдельных
фрагментов. Если надёжного перевода нет, сохраняется исходный китайский текст.

## Программная нормализация

- `14.18万` преобразуется в `141800`;
- цены сохраняются в CNY без сокращений;
- единицы мощности, энергии и объёма приводятся к единому написанию;
- тип двигателя, трансмиссии, привода и компоновки сохраняется устойчивым кодом;
- штатное оснащение и отсутствие/опция преобразуются в булевы значения;
- пустое или неизвестное значение не подменяется текстом `Нет`.

## Новые и существующие данные

Новые ответы нормализуются во время записи. Для данных, загруженных до
обновления словарей, существует постобработка:

```bash
make translate-db
```

Команда изменяет нормализованные поля пакетами. Перед её запуском следует
остановить парсер. Неизвестные строки остаются без изменений.
