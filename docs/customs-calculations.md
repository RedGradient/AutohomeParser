# Таможенные расчёты

Расчёт носит предварительный характер и не заменяет решение таможенного органа.
Каталожная цена Autohome не включает доставку и страхование до границы.

## Состав расчёта

Для поддерживаемого сценария сохраняются:

- `IMPORT_DUTY` — ввозная пошлина;
- `CUSTOMS_FEE` — сбор за таможенные операции;
- `RECYCLING_FEE` — утилизационный сбор;
- `EXCISE` — акциз для юридического лица;
- `VAT` — НДС для юридического лица.

`customs_calculations` хранит актуальный сценарий для комплектации и типа
импортёра, курсы, версию правил и снимок входных данных.
`customs_payment_results` содержит отдельные платежи и причины безопасного
отказа.

## Цена и курсы

Сначала используется положительная `guide_price_yuan`, затем
`dealer_price_yuan`. Официальные курсы CNY и EUR загружаются из ежедневного XML
Банка России. Если ставка зависит только от объёма двигателя, цена может иметь
источник `NOT_REQUIRED`.

Поскольку стоимость доставки и страхования неизвестна, расчёт таможенной
стоимости получает предупреждение `INCOMPLETE_CUSTOMS_VALUE`.

## Ручной запуск

Полный локальный перерасчёт:

```bash
make calculate-customs-payments
```

Только отсутствующие или изменившиеся сценарии:

```bash
make calculate-customs-payments \
  CALCULATE_CUSTOMS_PAYMENTS_ARGS="--mode stale"
```

Проверка без записи:

```bash
make calculate-customs-payments \
  CALCULATE_CUSTOMS_PAYMENTS_ARGS="--limit 100 --dry-run"
```

Production Docker:

```bash
docker compose -f compose.prod.yaml run --rm api \
  python -m autohome.cli.calculate_customs_payments
```

## Автоматическое обновление

Celery beat ежедневно в 08:00 `Europe/Moscow` проверяет CNY и EUR. Время задают
`CBR_RATES_UPDATE_HOUR` и `CBR_RATES_UPDATE_MINUTE`.

При изменении курса выполняется полный перерасчёт, после которого новый курс
фиксируется в `cbr_exchange_rates`. При неизменном курсе рассчитываются только
отсутствующие или устаревшие сценарии. Неуспешный полный перерасчёт не помечает
курс как применённый.

После успешного `autohome.cli.run_multi` также запускается инкрементальный
перерасчёт. Его
можно отключить аргументом `--skip-customs-recalculation`.

## Ограничения

- модельный год преобразуется в предполагаемую дату выпуска 1 июля;
- расчёт поддерживает товарные позиции ТН ВЭД 8702, 8703 и 8704;
- транспорт специального назначения 8705 и транспорт вне позиций 8702–8705
  автоматически не рассчитываются;
- пошлина для автобусов 8702 и грузовых автомобилей 8704 рассчитывается только
  для юридических лиц;
- типы кузова из каталога используются как признаки, но сами по себе не
  определяют код ТН ВЭД;
- неоднозначные MPV, пикапы и фургоны возвращают `MANUAL_REVIEW` или
  `AMBIGUOUS`; для их классификации могут потребоваться количество мест, массы,
  грузоподъёмность, размеры грузовой части и другие конструктивные признаки;
- для тарифных веток 8702 и 8704 необходимы подтверждённые параметры, от
  которых зависит ставка: тип энергии, возраст, объём двигателя, количество
  мест или разрешённая максимальная масса;
- отсутствие обязательных данных не заменяется нулём или предположением по
  названию и фотографии;
- недостаток данных возвращает безопасный статус вместо приблизительной суммы;
- чистые электромобили физлиц требуют совокупного таможенного платежа;
- пиковая мощность электродвигателя не заменяет максимальную 30-минутную
  мощность, когда нормативное правило требует именно её;
- доставка, страхование и иные расходы сейчас не включаются.
